# 内容视频播放器

`src/components/ContentVideo.tsx` 和同名 CSS Module 提供统一控件；`src/lib/content-playback.ts` 管理本站注册播放器及标签页会话状态。`EvidenceVideos` 的现有首页、解决方案与 About 调用全部复用；产品详情目前只有图片，未添加视频。未接入页面的 ScrollExpand 视频分支也复用相同控件。

## 播放规则

- 当前页面/非隐藏章节、文档可见、实际可见比例至少一半时，协调器选择主要可见视频，静音提出首次播放请求。不使用 video autoPlay 属性，不循环。
- 同一稳定媒体 ID 在本标签页会话内最多自动启动一次。sessionStorage `one-g-content-playback-v1` 仅保存 started、stopped、ended，存储不可用则使用内存。真实 playing 才记录 started；ended 单独记录，不保存观看位置或身份。
- 用户手动播放优先，暂停前一注册实例。离屏、后台或切章暂停；返回后需手动继续。实例存续期间保留时间，刷新仅保留是否已开始/停止/结束，不恢复时间。
- play Promise 使用版本与当前播放意图，过期结果不能恢复用户已暂停的播放。浏览器拒绝自动播放只显示播放入口，资源错误提供手动重试。
- 暂停/结束只对媒体画面加柔和模糊，控件保持清楚；中央按钮继续或重播。真实 ended 保留结束帧，重播只在手动操作后归零。

## 控件与回退

底部渐变、4px 品牌蓝进度、播放/暂停、等宽时间、静音/音量和外壳全屏。没有字幕轨不生成空字幕按钮；传入真实 tracks 时保留字幕入口。全屏优先外壳，必要时使用 WebKit 原生视频全屏；原生全屏/字幕显示时关闭暂停滤镜。原生全屏与移动 Safari 尚需实机复核。

监听器安装完成才关闭原生 controls，无 JS 保留原生控件。减少动态效果和 saveData 不强制自动播放；减少动态取消过渡，saveData 使用轻暗遮罩。控制栏在暂停、结束、错误、拖动或聚焦时保持可见，隐藏时不拦截点击。

About 只对注册于章内的播放器发暂停；播放器范围的滑块、按钮、键盘和触摸输入不触发切章。快捷键只在播放器外壳自身聚焦时处理，不再处理原生滑块/按钮的按键。

素材、字幕、来源数据及布局归属不改变，不恢复媒体下方的小字。真实证据和未覆盖项见 `docs/reviews/content-player-20261105/`。


## 2026-11-05 音量、画面操作与平滑进度

音量使用官方 React Bits `ElasticSlider.tsx` / `.css`，0–100 映射真实 video.volume。volumechange 是外部状态来源；静音显示零，实例保留上次非零音量。只有明确用户操作才解除静音，写入失败时禁用滑块并提示使用系统音量。减少动态效果关闭弹性和增厚。详细来源和许可证见 THIRD_PARTY_NOTICES.md。

媒体表面是独立点击层，含黑边；按钮、字幕、进度与音量层不属于表面。单指移动超过 8px 或非主指针取消点击，保留纵向浏览和缩放。结束时仅明确重播按钮归零。原生控件回退不挂表面层。

`src/lib/video-progress.ts` 是进度唯一绘制来源：单个 RAF 读取实际 currentTime，并同时写入原生 range.value、填充变量及可访问值。未对播放时间取整；只有时间文字按秒更新，不逐帧设置 React 状态。暂停、缓冲、离屏、后台、控件隐藏和卸载停止刷新，再显示时立即读取真实位置。拖动预览优先，旧媒体事件不覆盖；定位不改变播放或静音意图。`src/lib/media-volume.ts` 负责有界、可验证的音量写入。

本轮证据、检查与设备限制见 `reviews/smooth-progress-20261105/REPORT.md`。
