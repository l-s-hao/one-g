# 按钮用途与装饰效果

两种效果基于用户提供的 Uiverse CSS：普通按钮来自 Cornerstone-04，购买按钮来自 cssbuttons-io。来源注释保留在 `src/components/button-effects.css`。不新增依赖，不复制示例的固定宽度、浮动、全局布局、字体或取消焦点规则。

## 共享实现

`src/i18n/Elements.tsx` 的 `LButton`、`LocalizedLink` 和 `LA` 支持明确的 `intent="ordinary" | "purchase"`。调用处按真实用途指定，不能根据中文/英文文案猜测。翻译先于装饰包装执行；真实 button/Link、事件、ref、提交类型和路由仍由原组件负责。装饰层 `aria-hidden`、`pointer-events:none`，不参与布局。

- 普通：4px 下/左、上/右两组边线；横向 0.3 秒，纵向 0.3 秒，延迟分别 0.3 / 0.5 秒；轻柔阴影。
- 购买：2px 直角外框、左侧短线、内部文字层及三个 key；短线 1.5625rem → 0.9375rem，文字向左 0.5rem，颜色/文字 0.3 秒，缺口 0.5 秒。
- 缺口使用边框层的透明 `clip-path`，不使用遮挡背景色。页面、卡片和半透明局部导航都不会出现纯色色块；照片不变。
- 日夜颜色读取 `--text`、`--bg`；购买悬停反转填充/文字，保留现有主题管理。

## 接入范围

普通操作覆盖首页入口及展开详情、商品了解/规格/返回、解决方案了解/展开、深度定制入口与返回、客服填写/预览/编辑/关闭、登录/验证码、账户操作、购物车浏览与历史项目移除、订单结果返回、兼容路由的文字操作和图片菜单的查看全部。

购买用途覆盖商品的购买入口、产品局部导航购买入口、加入购物车、去结算及现有演示订单创建主按钮。购物车结算沿用 `NavigationLink` 登录检查。加入购物车和去结算替换此前 Shimmer 装饰，保留原业务处理；不清理共享动画依赖。RoboDock 不可销售状态、登录关闭状态、演示订单限制不变。没有新增真实支付或 SONIC Link 购买能力。

导航栏目/图标、关闭 X、筛选 Chip、Tab、数量输入、单选/复选/开关、日夜/语言控件和整张卡片不接入新边框效果。实际 button 与显式按钮链接的各状态取消文字下划线；正文、协议、订单记录与 Footer 普通栏目链接继续保留原样。

## 动画与可访问性

仅精确鼠标并支持 hover 时播放效果。禁用、`aria-disabled`、`aria-busy` 不播放新悬停反馈。减少动画时取消边线移动、缺口和文字过渡，文字不位移。保留 focus-visible。装饰与文字的内部动画不操作外层卡片、GSAP Flip 或 Motion 节点。

按钮保留原外部 padding、尺寸级别与布局；购买文字层为短线预留内部空间，中英文按原字体自然排版。
