本轮保持搜索入口、Header 和业务边界，完善已有共享搜索，不新增结果路由、Provider、依赖或外部服务。北极星：始终知道正在编辑什么、搜索了什么，以及下一次操作会查询还是打开内容。

## Apple 实际参考与本站适配

在 Chromium 中实际访问 [Apple 中国官网](https://www.apple.com.cn/)，分别观察1440px桌面与390px触屏模拟。

| 实际观察 | ONE-G 适配 |
| --- | --- |
| 导航下方展开大输入与快速链接 | 保留横向面板与四个本站真实入口，日夜使用本站主题 |
| 逐字输入后分为链接建议、搜索结果建议 | 本站明确区分 destination 与 query 动作，紧凑建议最多6项 |
| Enter 进入官网搜索结果 URL | ONE-G 没有独立结果路由，继续在面板进入完整结果状态 |
| 链接建议与查询建议的目标不同；查询建议实测可重定向到分类 | 本站按动作类型执行，不按文案猜测，不复用 Apple 服务或商品资料 |
| 清除按钮清空输入并保持焦点 | 本站同时清除旧选择/提交状态，明确返回快捷入口 |
| Escape 关闭并返回搜索入口；链接、结果与浏览器返回可实际操作 | 保留原生 Link、焦点恢复、basePath、注册离页保护 |
| 无关词提交后出现无匹配与恢复建议 | 本站不生成无依据的推荐，提供清空/浏览全部 |

未核实：Apple 拼写错误、无关词的稳定即时建议规则，以及清空后建议列表的稳定恢复时点；观察中这些列表曾保留上一关键词内容。不能据此推断内部算法或缓存。实际系统手机软键盘、Safari 与系统输入法也未取得。本站的受控近似匹配、显式修正、查询快照和准确数量是本站实现，非 Apple 算法复刻。300ms展开与280ms商品输入展开为本站既有参数，未测量或声称 Apple 参数。

## 状态与操作

各调用方拥有独立 `draftQuery`（现有query属性）；共享组件用提交快照保存 `committedQuery`、命中列表及结果/无匹配/异常状态。主动选择保存候选ID及所属查询，跟随真实焦点；输入变化、清空、回到输入框会清除选择。关闭由各入口已有active/open状态管理，保留当前输入与仍适用的结果，不重新开面板。

- 关闭：不播报结果、无后台请求；沿用已有浮层计时器清理与互斥。
- 打开且空输入：顶部四个真实快捷入口，商品搜索不生成空结果提示。
- 输入建议：最多6项，只呈现当前草稿的真实匹配及明确操作。
- 已提交有结果：回显原始提交词，展示全部命中，数量与内容条目一致；操作行不计入结果数。
- 已提交无匹配：保留提交词，提供清空和浏览全部。
- 本地索引异常：与无匹配分开，原位置重试；输入新词立即废弃旧提交。

当前索引完全同步，没有真实查询等待或远端请求，因此没有假 pending、Loader、防抖或取消请求状态，也不存在异步结果倒序。只有真实异步能力接入时才应增加请求取消/版本和区域加载指示。本轮异常测试使用受控本地索引异常，不冒充网络失败。

| 动作 | 语义与处理 |
| --- | --- |
| destination | 名称+类型，真实 Link 打开正式内容；支持原生新标签、修饰键与离页保护 |
| query | “搜索 + 当前原始输入”，明确提交查询，留在结果面板 |
| correction | “改为搜索 + 正式名称”，只有明确选择才改变输入并提交，不立刻跳详情 |

顶部无主动选择时，Enter 始终查询，唯一模糊项也不误跳。商品入口仅唯一明确名称、型号或已确认别名允许 Enter 直达；G1/Pro 歧义、分类、前缀和拼写推荐保留选择。建议列表用原生链接/按钮，上下键移动实际焦点，Enter 原生确认；没有不完整的 combobox/listbox 或嵌套交互元素。表单统一处理提交，并读取当前 FormData，避免快速输入后提交旧值。

## 匹配和内容边界

继续从已有9商品、4方案、3公开导航适配索引，不复制资料。NFKC、空格、连字符、大小写归一化仅用于匹配，输入和提交回显保留原文。正式名称、历史别名、前缀、包含优先；纯拉丁较长名称才允许受限编辑距离，短数字型号不猜测。RobotDock 命中正式 RoboDock。RoboDack 可明确修正为 RoboDock；RoboDoc 是前缀候选，不能自动跳转。

RoboDock 保持商品介绍身份，SONIC Link 保持方案身份；商品入口不混方案。搜索不改变分类、不加购、不开放未销售商品。全站内容链接与商品详情由原数据及路由 helper 取得，未新增占位地址。

## 反馈、焦点与视觉

提交结果显示真实数量，无精确匹配时标为“相关结果”，另保留简短的“未找到完全匹配的结果 / 你可能想找”。一个状态区域只在明确提交/重试产生有意义的播报，输入建议不逐字打断；可见数量关闭自己的重复live播报。

复用300ms面板、280ms商品输入展开与原焦点/hover；建议更新不重播开场。减少动态直接展示。搜索打开时只轻暗底页，避免下方原商品被误读为结果；没有全屏blur、焦点约束或新输入拦截，依旧非模态、不锁页面。保留原玻璃降级。

清空与关闭是不同按钮。清空保持输入焦点；普通关闭返回入口；导航成功不拉回旧Header。注册结果导航仍经过原离页保护，取消离页不丢表单。组合输入中的Enter防提交，失焦清理组合标记；事件回归不能替代真实系统输入法验证。浏览器返回时沿用原路由重挂策略关闭Header，商品分类继续由原URL维护，不新增搜索观看记录或存储。
