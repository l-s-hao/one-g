## 判断规则与代表区域

按用途而非字号分类：A 重复标签/标题/动作；B 真实介绍；C 条件/格式/后果；D 必要概念；E 重要状态/来源/事实限定。A 从渲染移除，B 归入现有详情，C/D/E 在决策位置保留。没有发现 A 的区域不强行删文案。

| 代表原文/区域 | 分类与处理 | 真实位置/理由 |
| --- | --- | --- |
| 商品卡片 product.subtitle，如“通用机器人小背包” | B，从概览移出 | RoboDock `/products/robotdock` 及其它 `/products/[id]` 已有相同副标题，不再复制；名称、图片、价格、状态和操作保留 |
| 卡片 badge“概念产品 · 配置预览”后又说“概念阶段，…” | A+E，仅删重复前缀 | 保留完整“暂未开售；名称、外观、接口、适配及交付待确认”，商品数据本身不改 |
| 巡检说明“以视觉采集和机器人端设备接入为起点，讨论现场观察任务。” | B，保留在现有连续分区 | `/solutions#inspection` 本身是详情，提升正文可读性，无需增加层级 |
| 注册密码规则、地区说明、验证码、实名选填、离页不保存提示 | C/D/E，保留 | 原 Label、aria-describedby、错误映射、required/optional、业务状态机均保留；不是无意义填充提示 |
| 深度定制“登录后填写深度定制需求，当前仅支持前端预览。” | A+C+E，精简重复动作 | 使用现有“需求填写需登录，当前仅供前端预览。”，紧邻客服入口 |
