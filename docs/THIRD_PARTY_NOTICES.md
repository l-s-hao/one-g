## React Bits ElasticSlider

来源：https://reactbits.dev/r/ElasticSlider-TS-CSS.json；文档：https://reactbits.dev/components/elastic-slider；官方仓库：https://github.com/DavidHDev/react-bits。2026-11-05 获取，registry 未提供版本号；原文件 SHA-256 见 `reviews/smooth-progress-20261105/registry-install.json`。

使用原始 TS/CSS，并做受控音量、指针取消清理、减少动态效果与 React refs lint 的局部适配。新增 Hugeicons React 1.1.10 和 core-free-icons 4.4.0；既有 Motion 保留，组件未引入 Motion。shadcn 4.23.0 已安装依赖，但远端颜色资源 TLS 失败，因此从取得的同一官方 JSON 写入文件。
