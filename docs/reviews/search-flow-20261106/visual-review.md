## 问题 1：搜索面板与背景正文缺少清晰视觉交界

观察：1440-complete-results 下沿只露出三张商品卡片的“了解更多”按钮；1440-correction 和 390-correction 从商品图片中段开始露出背景卡片；1440-no-result 在下沿露出被截掉上半部的按钮。搜索区与底页又采用相近表面色，背景卡片容易被读为刚才查询的附属结果。手机中 RoboDock 推荐下紧接 Vision V1 / RGB-D 卡片，这种关联尤其容易误读。

影响：用户能看清搜索结果行，但不容易立即确定列表在哪里结束；与“搜索了什么、下一次是查询还是打开内容”的北极星有冲突。

目标：保留现有非模态面板、Header 和正文，只把现有面板与背景的层级交界表达清楚，不新增说明文案、不改页面内容。验收时在相同四个状态里，一眼能区分搜索结果与原页面，尤其不把截断的商品卡片认作 RoboDock 的结果。

目标：在现有数量或分组文字中准确表达相关命中／推荐口径，无须添加一段说明。验收时，“无完全匹配”的状态和数量不产生表面矛盾，且仍能直接分清改词查询与打开商品。
