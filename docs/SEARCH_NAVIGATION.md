## 毛玻璃实际原因

`colors.css` 遗留 `html .site-header { background: var(--surface); }`，使根层为不透明白色，伪元素即使已有 blur 也无法采样真实正文。已删除该声明，明确根层透明，滤镜仅在有限背景伪元素上。不是增加文字滤镜或整个 Header 的 opacity。

| Chromium 桌面日间 | 修复前 | 修复后 |
| --- | --- | --- |
| 根层 computed background | rgb(255,255,255) | rgba(0,0,0,0) |
| 背景伪元素 | rgba(247,244,238,.94) | rgba(247,244,238,.84) |
| computed backdrop-filter | blur(12px) | blur(14px) |

源码同时声明标准与 WebKit 属性；本机 Chromium 的前缀 computed 值为空字符串，不宣称 Safari 已验证。真实图片、文字、播放视频经过导航时，对同位置玻璃/强制纯色分别截图；另有明确标注的受控高对比条纹对照。纯色背景截图本身不足以判断滤镜失效。

保留纯色基础、能力检测、减少透明、强制颜色、省流量及原低内存/线程组合策略。窄屏粗指针仍采用保守纯色，属于产品策略，不是 GPU 检测；减少动态效果不等于减少透明。内部 `?navbarSurface=solid` 可强制纯色。降级同步关闭滤镜并恢复不透明色。搜索/设置自身使用实色表面，没有多层玻璃。

## 顺序与浮层

桌面：左侧 Logo；中间商品中心、解决方案、了解公司；右侧搜索、用户、购物车、显示设置。移动端保留既有账户菜单与移动导航职责，显示设置仍最后；无重复左侧搜索。原 Header 高度、全宽、占位、路由胶囊与图片抽屉保持。

搜索沿用 Header 单一面板状态与开关计时器，打开取消其它待开面板。300ms 导航下方全宽展开，内部最大 920px；非模态，不锁正文、不声明 aria-modal。普通关闭恢复入口焦点，结果导航不强拉回旧 Header。内容区滚动且只在打开时订阅 visualViewport/窗口变化；卸载与关闭清理。手机软键盘高度以受控 viewport 事件测试，非实机输入法结论。

## 共用数据与匹配

`src/lib/site-search.ts` 从现有商品查询、方案、导航及正式路由 helper 建立稳定 ID 索引，未复制商品资料。包含 9 个公开商品（含 RoboDock 概念介绍）、4 个方案、3 个公开主页面；不索引用户、订单或草稿。RobotDock 为历史别名；背包/小背包依据既有 robotdock 正式副标题及套装资料。正式结果仍显示 RoboDock。

NFKC、大小写、空格和连字符归一化；名称、明确别名、前缀、包含依次匹配。没有普通命中时才对至少 5 字母的拉丁名称作受限编辑距离推荐，最多 1～2 字符差且相似度至少 80%；数字型号与短中文不作拼写猜测。G1 与 G1 Pro 独立。RoboDoc 属于名称前缀，RoboDack 才是编辑距离近似；两者均不直接跳转。

| 行为 | 顶部搜索 | 商品搜索 |
| --- | --- | --- |
| 范围 | 公开商品、方案、必要页面 | 全部公开商品，与分类无关 |
| 空输入 | RoboDock、遥操作方案、商品中心、了解公司真实快捷链接 | 不生成搜索结果 |
| Enter | 提交最新输入，在面板展示结果 | 唯一明确名称/别名才直接进入详情 |
| G1 / 类别 | 候选列表 | 保留多个候选，不自动挑第一项 |
| 相近 / 无关词 | 明确推荐 / 正常无结果 | 明确推荐 / 正常无结果 |
| SONIC Link | 对应遥操作方案 | 不混入商品 |
| 主动选择 | 真实 Link 导航 | 真实商品 Link 导航 |

共享 `SearchBox` 使用原生 form、即时本地匹配，无假 loading/防抖旧查询。提交读取当前 FormData；组合输入期间 Enter 不提交。上下键移动到真实候选链接，Enter 原生确认；没有只贴角色的半套 combobox。商品明确命中也点击真实链接，因此注册离页保护仍能拦截。查询纯文本渲染，不注入 HTML/正则/地址。

`ProductSearch` 有独立 query，工具栏图标向右展开，总宽最多 384px；不足时工具栏换行。分类与 Flip 保持，查询不改变分类。普通失焦不卸载候选；外部点击/Escape 关闭，返回触发器。Header 获得焦点或悬停时关闭局部结果，避免双层交互；不会清空独立查询。无滚轮拦截或全局输入锁。
